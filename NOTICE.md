# Notice

This repository does not contain Topway/TS18 proprietary APK binaries or signing
keys. `reference/` records only hashes and derived static findings from binaries
supplied by the device owner.

`xposed-stubs` contains minimal compile-time declarations written for this
project. They are never packaged into the LSPosed APK; runtime classes are
provided by the installed Xposed/LSPosed environment.
